How to use the application

After opening the application, you will be required to enter a student name and then load the profile. From the drop down menu of the animals you can select any category, that done you can press the button that says speak 🔊, this will pronounce a sentence with the name of the animal on display at the end, other of these animals are exitnct while others are mythical, to learn more information copy the name and paste it into Wikipedia search or Gemini. The other button ⏩ is for selecting the next animal while the other button ⏪ is for selecting the previous one. From here there is a quiz questions, a sentence a student must complete with the name of the animal on display, the quiz is optional and it focuses on accumulating a highest score and passing many levels, and it also shows the student's level of progress. Once a profile is created it will always be in the application unless the browser is cleared, for more information reach out using the support button below.
